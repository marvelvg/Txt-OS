Penjelasan : 
Memanggil system call menimbulkan tambahan latency akibat terjadinya 
context switching. Untuk mengurangi frekuensi system call, 
program dapat menggunakan User-Buffer I/O, sehingga data dibaca dan 
ditulis dalam satuan ukuran blok (block size) yang lebih besar. 
Misalnya, saat menyalin 2 MB data menggunakan perintah dd, 
jika ukuran blok diatur bs=1 dan count=2097152, 
sistem harus melakukan 2.097.152 kali 
system call read() dan write(), sehingga waktu 
eksekusi menjadi sangat lama. 
Dengan meningkatkan ukuran blok menjadi 1 KB (bs=1024 count=2048), 
jumlah I/O berkurang drastis menjadi 2.048 kali, 
mempercepat waktu eksekusi secara signifikan. 
Selanjutnya, menggunakan blok 4 KB (bs=4096 count=512) hanya membutuhkan 
512 system call, dan blok 8 KB (bs=8192 count=256) hanya 256 system call, 
membuat eksekusi menjadi lebih cepat lagi. 
Analisis waktu dari perintah time menunjukkan bahwa waktu user space 
(user time) tetap kecil karena program tidak melakukan komputasi rumit, 
sementara waktu kernel space (system time) menurun drastis 
seiring meningkatnya ukuran blok, karena context switching yang mahal 
dapat diminimalkan. Real time, atau total waktu eksekusi, juga berkurang 
seiring peningkatan blok karena sebagian besar overhead awal berasal 
dari system call. 
Dengan menggunakan sudo tune2fs -l /dev/nvme0n1p2 | grep "Block size", 
dapat diketahui bahwa ukuran blok sistem file 
adalah 4096 bytes. Hal ini menjelaskan mengapa blok yang selaras dengan ukuran bawaan file system (bs=4096 atau 8192) lebih efisien: sistem cukup mengambil satu blok penuh, tanpa harus memecah-mecah data, sedangkan blok yang tidak selaras (misal bs=5000) menimbulkan Read-Modify-Write, memperlambat proses. Meskipun memperbesar ukuran blok dari 1 byte ke 4 KB atau 8 KB mengurangi jumlah system call dan mempercepat eksekusi, peningkatan performa akan mencapai titik jenuh karena batas kecepatan berpindah dari overhead CPU 
ke kecepatan fisik media penyimpanan. Di sinilah peran penting pustaka standard I/O (stdio.h) di bahasa C: fungsi seperti fopen(), fread(), dan fwrite() menyediakan buffering otomatis di user space, menyelaraskan ukuran data secara optimal, dan menyembunyikan kerumitan system call. Sebagai contoh, menulis karakter satu per satu dengan fputc() tidak akan memanggil write() sebanyak karakter yang dikirim, karena stdio akan menampung data dalam buffer hingga penuh sebelum melakukan satu kali system call, sehingga meningkatkan efisiensi tanpa harus mengetahui ukuran blok hardware secara manual.
